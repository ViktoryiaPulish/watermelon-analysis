# Внешняя торговля Республики Беларусь: ТН ВЭД 080711 «Арбузы свежие», 2008–2021

Анализ импорта и экспорта арбузов по данным Национального статистического комитета Республики Беларусь. Декомпозиция временных рядов, прогноз на 2022–2024 гг., корреляция с курсом BYN/USD.

## Что внутри

Анализ состоит из 4 блоков: **Декомпозиция**, **Прогноз**, **Корреляция с курсом**, **Визуализация**. В каждом блоке — расчёты, графики и текстовые выводы.

## Данные

- **Источник торговли:** Национальный статистический комитет Республики Беларусь.
- **Источник курса:** Национальный банк Республики Беларусь.
- **Период:** 2008–2021 (торговля), 2008–2024 (курс).
- **Товар:** ТН ВЭД 080711 — арбузы свежие.
- **Единицы:** кг, тыс. USD, BYN/USD.

## Структура репозитория

- `data/` — исходные файлы `.xlsx`
- `output/` — результаты: графики `.png` и таблицы `results.xlsx`
- `watermelon_analysis.py` — основной скрипт
- `Задание 2.pdf` — текстовый отчёт с методологией, графиками и выводами
